# 02. UI 구현 지침

## 디자인 방향
- 친근하고 산뜻한 주방/식재료 분위기
- 밝은 크림색 또는 흰색 배경, 녹색 계열 포인트
- 큰 입력 영역과 명확한 단계 안내
- 모바일에서 사진 업로드와 재료 편집이 편리해야 한다.

## 화면 순서
1. 헤더: 냉장고 구조대 로고와 한 줄 소개
2. 재료 등록: 직접 입력 / 사진으로 분석 탭
3. 사진 업로드: 여러 장 선택, 최대 5장, 장당 8MB 안내, 미리보기와 개별 삭제
4. 사진 분석 결과: 재료 후보를 체크박스/텍스트 입력으로 수정, 추가, 삭제
5. 요리 조건: 인원수, 선호 음식, 소비기한 임박 재료(선택)
6. 요리 추천: 3개 카드, 추천 이유, 보유 재료, 추가 재료, 조리 시간, 난이도
7. 상세 레시피: 재료 분량과 단계별 조리법
8. 피드백 입력 및 최신순 목록

## 주요 인터랙션
- 파일 선택 후 즉시 미리보기 표시
- 분석 버튼 클릭 시 진행 표시 및 중복 클릭 방지
- 분석 결과가 없으면 재료 확인 영역을 숨긴다.
- 사용자가 재료를 확인/수정한 뒤 '이 재료로 요리 추천' 버튼을 활성화한다.
- 직접 입력 모드에서는 재료 목록을 추가/삭제할 수 있다.
- 추천 카드 선택 시 상세 레시피를 보여준다.
- 피드백 제출 후 입력 폼을 초기화하고 목록을 갱신한다.

## 상태 및 접근성
- 파일 형식/용량 오류, 분석 실패, 추천 실패, 피드백 오류를 텍스트로 안내한다.
- 로딩 중 버튼 비활성화 및 상태 문구 표시
- 입력마다 label 제공, 키보드 포커스 표시
- 사진이 없는 상태, 분석 결과가 없는 상태, 피드백이 없는 상태를 각각 안내
- 색상만으로 성공/오류를 표현하지 않는다.
