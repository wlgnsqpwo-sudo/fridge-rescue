# 05. 테스트 및 검증 체크리스트

## 준비
- [ ] Node.js 설치
- [ ] `npm install`
- [ ] `.env` 생성 및 OpenAI/Supabase 환경변수 입력
- [ ] Supabase SQL 실행

## 로컬
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속

## 사진 분석
- [ ] JPG/PNG/WEBP 사진 1장 업로드 및 미리보기
- [ ] 사진 여러 장(최대 5장) 업로드
- [ ] 개별 사진 삭제
- [ ] 6장 업로드가 차단되는지 확인
- [ ] 8MB 초과 파일이 거부되는지 확인
- [ ] 허용되지 않은 파일 형식이 거부되는지 확인
- [ ] 식재료 후보가 표시되는지 확인
- [ ] 불확실한 항목에 확인 필요 표시
- [ ] 분석 결과를 수정/삭제/추가할 수 있는지 확인
- [ ] 분석 실패 후 직접 입력 방식은 계속 사용할 수 있는지 확인

## 요리 추천
- [ ] 직접 입력 재료만으로 추천 가능
- [ ] 사진 분석 후 수정한 재료로 추천 가능
- [ ] 추천 3개가 표시되는지 확인
- [ ] 보유 재료와 추가 재료가 구분되는지 확인
- [ ] 상세 레시피가 표시되는지 확인
- [ ] 사용자가 입력하지 않은 재료를 보유 중이라고 표시하지 않는지 확인

## 피드백
- [ ] 로그인 없이 등록 가능
- [ ] 빈 내용 및 500자 초과 입력 차단
- [ ] 저장 후 목록 갱신
- [ ] 새로고침 후에도 데이터 유지
- [ ] 최신순 정렬 확인

## 보안/배포
- [ ] 사진이 분석 후 서버 임시 저장소에서 삭제되는지 확인
- [ ] 비밀 키가 브라우저 코드에 없는지 확인
- [ ] `.env`가 Git 상태에 포함되지 않는지 확인
- [ ] Vercel에서 사진 분석/추천/피드백 동작 확인
- [ ] 모바일 화면 확인
